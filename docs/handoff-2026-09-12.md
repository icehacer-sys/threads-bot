## 3. What was built today

### `src/reply-metrics.ts` (new, pure, no network)

| Export | Purpose |
| --- | --- |
| `shapeGrams(text, n=4)` | Word n-grams of a reply |
| `sharedShapeCount(a, b, n=4)` | Shared shapes between two replies |
| `nearDuplicates(replies, minShared=2, n=4)` | Pairs reusing a shape, worst first |
| `shapeClusters(replies, ...)` | Transitive groups of formulaic replies |
| `emojiProfile(replies)` | Glyph-agnostic emoji rates with trailing position |

Design principle behind both: **measure the shape, not the instance.** The old checks named a specific glyph and demanded exact equality, which is why both failures ran unseen.

Two properties that are deliberate, not bugs:

- Replies shorter than `n` words yield no grams and can never be near-duplicate flagged. `That's it.` × 2 belongs to the existing exact-duplicate check. The two detectors are complementary.
- `shapeClusters` linking is transitive, so a cluster can chain two formulas joined by a bridging reply. On the 09-11 night it grouped 17: the 11-reply histology correction plus the "dark cavity here" and "quietly for years" families. Read the cluster as "this many replies are formulaic" and the pair list for which exact shapes repeat.

## 7. Gotchas for whoever works here next

- **Local clones fall badly behind.** The bot commits state from CI constantly; this session started 175 commits behind. Always `git pull --ff-only` before touching `state.json`.
- **Never edit `state.json` while a run is live.** Each poll re-reads it from disk and `sync_repo` rebases the run's own commit on top, so your push is silently reverted. Cancel the run first.
- **The spend cap-day rolls at MIDDAY Cairo**, not midnight (`today()` in `src/state.ts` formats `now - 12h`). A daytime catch-up shares a cap-day with that same night's window.
- **`BOT_WINDOW_HOURS=16`** makes a post invisible to the bot 16 hours after it goes up, regardless of any window override.
